# 🏅 Summer Olympics Historical Dashboard | Tableau Project

## 📌 Project Overview

This project explores over a century of Summer Olympics history using Tableau dashboards and interactive visual analytics.

The dashboard was designed for a fictional International Olympic Committee (IOC) scenario to help promote future Olympic Games by highlighting historical trends, athlete participation, medal distributions, and event evolution.

The analysis focuses exclusively on the **Summer Olympics** using historical Olympics datasets from Kaggle.

---

## 🎯 Objectives

The dashboard was built to answer questions such as:

- How have Olympic events evolved over time?
- Which countries dominate medal counts?
- How has gender representation changed throughout Olympic history?
- Which disciplines contain the highest number of events?
- How has athlete participation changed over the years?

## 🔍 Key Insights

### 1. Olympic Participation Increased Dramatically

Athlete participation steadily increased across Olympic history, showing the global expansion of the games.

### 2. Gender Representation Improved Over Time

Female participation grew significantly in modern Olympics compared to earlier years.

### 3. Medal Dominance by Specific Nations

A small group of countries consistently dominated medal standings throughout Olympic history.
